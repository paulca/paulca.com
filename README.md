# paulca.com

Static personal site for [paulca.com](https://paulca.com), hosted on GitHub Pages.

- `index.html` — bio and links, browser default styles only.
- `microblog/` — static archive of the Pterodon microblog that previously ran at paulca.com (captured July 2026).
- `posts/` — individual archived posts, kept at their original `/posts/N` URLs so old links still resolve.
